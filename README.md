# Guppy

Gestor personal de proyectos de Nilo Vélez. Centraliza el estado, el contexto y las relaciones de todos sus proyectos para poder consultarlos desde cualquier sesión o agente.

- Panorama: [proyectos/index.md](proyectos/index.md)
- Cómo funciona: [AGENTS.md](AGENTS.md)

Para que un agente nuevo aprenda a trabajar con Guppy, basta con decirle: *"Conéctate a github.com/manuelstone/guppy y sigue su AGENTS.md"*.

Para dar de alta proyectos desde su propia sesión de Claude Code, instala la skill en el equipo con `npx skills add manuelstone/guppy -g -a claude-code` y di en el proyecto *"registra este proyecto en Guppy"*.
